# autoclicker
An auto clicker I wrote in python because there was nothing that was free and worked for MacOS.

Use `pynput` for gathering keystrokes and mouse positions. It tells you to click two positions because thats what I needed then when you press any button it creates the loop and if you press return the loop breaks and delete ends the initial keystroke listener. It's really basic and not really good but works for what I needed it to do.
